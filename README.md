# Tic-tac-toe in Portugol

[Leia em português](README.pt-BR.md)

A console programming exercise for two players sharing a terminal. The [Portugol source](jogo_da_velha.por) represents the game board as a 3×3 array, alternates between X and O, and checks rows, columns and diagonals for a winner.

## Explore the source

Open `jogo_da_velha.por` in [Portugol Studio](https://github.com/UNIVALI-LITE/Portugol-Studio) to inspect the code. The exercise uses separate row and column prompts with coordinates from `0` to `2`. For example, row `1` and column `1` select the center square.

The original exercise has limitations in input validation and turn counting. Compatibility with current Portugol Studio releases has not been verified.
